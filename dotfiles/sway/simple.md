# Aide-mémoire — groupes & fenêtres

`$mod` = touche Logo/Super (Windows).

## Faire un groupe

1. `$mod+v` (ou `$mod+b`) → prépare un split (la prochaine fenêtre s'ouvre dessous / à droite)
2. ouvre une fenêtre (`$mod+Entrée`) → elle rejoint le split
3. `$mod+w` → transforme le split en **groupe d'onglets**
4. `$mod+a` → sélectionne le **groupe** entier (pour le déplacer/nommer)

## Raccourcis groupes

| Touches | Action |
|---|---|
| `$mod+b` / `$mod+v` | split horizontal / vertical |
| `$mod+w` | grouper en onglets (tabbed) |
| `$mod+t` | grouper en pile (stacking) |
| `$mod+e` | repasser en split |
| `$mod+a` | sélectionner le groupe parent |
| `$mod+Maj+m` | **nommer** le groupe (sélectionner avec `$mod+a` d'abord) |
| `$mod+Alt+m` | enlever le nom du groupe |
| `$mod+Maj+w` | **tout aplatir** en onglets (quand je suis perdu) |

## Repères visuels

- Onglet du **conteneur où je suis** → bleu clair `#6ebadd`
- Un conteneur s'affiche toujours `T[…]` (tabbed), `S[…]` (stacking), `V[…]`/`H[…]` (split) ; une fenêtre simple montre son titre normal
- Nom d'un groupe → affiché entre crochets `[nom]` dans la barre de titre

## Autres

| Touches | Action |
|---|---|
| `$mod+Entrée` | terminal |
| `$mod+q` | fermer la fenêtre |
| `$mod+x` | lanceur d'applis |
| `$mod+f` | plein écran |
| `$mod+1..0` | aller au workspace 1..10 |
| `$mod+Maj+1..0` | envoyer la fenêtre au workspace 1..10 |
| `$mod+flèches` | déplacer le focus |
| `$mod+Maj+flèches` | déplacer la fenêtre |
| `$mod+Alt+Flèche-Haut` | changer le fond d'écran |
| `$mod+Maj+c` | recharger la config |
